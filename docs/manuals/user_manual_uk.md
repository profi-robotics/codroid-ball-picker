# Інструкція користувача: система Pick-and-Place Codroid

## 1. Призначення та аудиторія

Цей документ призначений для операторів системи Pick-and-Place на базі Estun Codroid, OAK-D та грипера OnRobot 2FG7.

Мета інструкції: дати практичний покроковий порядок запуску, калібрування, ручної та автоматичної роботи, безпечної зупинки і базового відновлення після помилок.

## 2. Безпека та передумови

Перед початком роботи перевірте:

1. Робоча зона очищена від зайвих предметів і рук оператора.
2. Натискання аварійної зупинки доступне та зрозуміле всім, хто поруч.
3. Камера OAK-D закріплена стабільно, маркери в полі зору.
4. Кабелі робота, камери та Compute Box не натягнуті.
5. Грипер 2FG7 механічно справний та підключений.

Правила під час руху робота:

1. Не входьте в робочу зону під час автоматичної програми.
2. Якщо з'являються аварійні стани, негайно зупиняйте рух.
3. Після Emergency stop виконуйте тільки контрольований перезапуск.

## 3. Системні вимоги

### 3.1 Апаратна частина

1. Робот Estun Codroid.
2. Камера OAK-D (USB 3.0).
3. Грипер OnRobot 2FG7 та OnRobot Compute Box (за потреби захвату).
4. Маркери робочої зони:
   - `data/markers/corner_markers/top_left/aruco_4x4_id1.png`
   - `data/markers/corner_markers/bottom_right/aruco_4x4_id2.png`
5. Калібрувальна плита робота (або її друкована/3D-версія).

### 3.2 Програмна частина

1. Python 3.10-3.12.
2. Залежності встановлено через `uv install`.
3. Запуск UI:

```bash
python run_codroid_picker.py --debug
```

4. Інтерфейс доступний за адресою `http://127.0.0.1:8050`.

### 3.3 Мережа

1. Хост із UI повинен мати доступ до робота.
2. Для грипера потрібен доступ до Compute Box (типово `192.168.101.95:41414`).

## 4. Запуск і підключення

1. Запустіть застосунок командою:

```bash
python run_codroid_picker.py --debug
```

2. Відкрийте UI і перейдіть у **Setup & Connections**.
3. Перевірте статус камери:
   - `Camera: live` або відповідний локалізований стан.
4. Натисніть **Test robot connection** для перевірки зв'язку з роботом.
5. Для 2FG7:
   - Вкажіть **Compute Box IP Address**.
   - Увімкніть **Enable gripper connection**.
   - Натисніть **Test gripper**.

Результат етапу: камера, робот і (за потреби) грипер мають бути в стані online/ready без активних аварій.

## 5. Калібрування

### 5.1 Калібрування камери

1. Вкладка **Calibration**.
2. Запустіть **Camera calibration**.
3. Забезпечте стабільний огляд ChArUco-дошки до завершення.
4. Переконайтесь, що збережено калібрувальний бандл (стан `ready/loaded`).

### 5.2 Калібрування робочої зони

1. Розмістіть маркер ID 1 у верхньому лівому куті робочої зони.
2. Розмістіть маркер ID 2 у нижньому правому куті.
3. Перед обчисленням переконайтесь, що:
   - увімкнено live-потік камери (`Camera: live`);
   - завантажено або виконано калібрування камери.
4. Запустіть обчислення робочої зони (**Compute workspace**).
5. Переконайтесь, що workspace збережено.

### 5.3 Калібрування робота

1. Запустіть **Begin calibrating robot**.
2. Послідовно навчіть 3 точки на калібрувальній плиті.
3. Дочекайтесь verification move.
4. Переконайтесь, що дані записані у `data/robot_calibration.json`.

### 5.4 Детекція маркерів плити

1. У сценаріях із платою запустіть **Detect plate markers**.
2. Перевірте, що гомографія/Coord5 застосована без помилок.

## 6. Навчання точки скидання (Drop)

1. Перейдіть до **Applications > Pick & Place**.
2. Виведіть робот у бажану точку вивантаження.
3. Виконайте команду навчання Drop (teach/record drop position).
4. Перевірте відображені координати та орієнтацію.
5. Виконайте тестове повернення до Drop для перевірки досяжності.

Рекомендація: після повторного калібрування робота перевчіть Drop-позицію.

## 7. Ручні операції

### 7.1 Ручний підбір найближчого об'єкта

1. Переконайтесь, що модель детекції завантажена.
2. Натисніть **Pick closest object**.
3. Контролюйте етапи підходу:
   - спочатку робот переводить TCP по XY без зміни висоти;
   - орієнтація фланця (вісь C) змінюється лише над ціллю;
   - після цього виконується спуск на висоту pick.
4. Якщо ціль у щільному кластері, ручний pick може бути скасовано для уникнення дотику сусідніх об'єктів.

### 7.2 Ручний цикл pick-and-place

1. Переконайтесь, що Drop-позиція навчена.
2. Натисніть **Pick and place target** (ручний цикл).
3. Перевірте, що об'єкт перенесено в Drop-зону.
4. Якщо після закриття грипера не підтверджено захват, цикл зупиняється з помилкою і етап Drop не виконується.

Якщо захват не відбувся, перевірте:

1. Ширину/силу/швидкість грипера.
2. Висоти approach/pick/drop.
3. Точність калібрування та актуальність plate tracking.

## 8. Автоматичний режим Auto Pick & Place

1. Перед запуском переконайтесь, що:
   - камера в стані `Camera: live`;
   - завантажено модель детекції;
   - визначено workspace;
   - завершено калібрування робота;
   - задано Drop-позицію.
2. Увімкніть **Auto pick & place**.
3. Налаштуйте **Target class** (типово `orange`).
4. Налаштуйте **Drop ignore radius (mm)**, щоб ігнорувати об'єкти біля точки скидання.
5. Запустіть Auto-режим.
6. У **Setup -> Safety guards** налаштуйте камеру безпеки:
   - **Enable camera safety pause**: вмикає автоматичну паузу програм при виявленні людини;
   - **Camera safety zone**: `Workspace only` або `Full frame`;
   - **Safety stop labels**: список YOLO-міток (теги), які викликають паузу.

Поведінка режиму:

1. Цілі ранжуються за досяжністю та локальним зазором до сусідніх об'єктів.
2. Для вибраної цілі спочатку підбирається безпечний кут осі C (мінімальна додаткова ротація).
3. Якщо ротація не дає безпечного зазору, система робить до 2 бокових підштовхувань відкритим грипером, відходить, оновлює детекцію й повторно планує pick.
4. Якщо кластер не вдалося розділити, система переходить до наступної цілі в поточному циклі.
5. Підхід виконується у послідовності: XY-транзит на поточній висоті -> підхід по Z -> вирівнювання орієнтації над ціллю -> фінальний спуск на pick.
6. Якщо виявлено мітку з **Safety stop labels** у вибраній зоні, активна програма переходить у паузу.
7. Коли таких міток більше не видно, програма автоматично відновлюється.
8. Якщо після закриття грипера не підтверджено захват, робот відходить, відкриває грипер і одразу повторно сканує робочу зону без переходу в Drop.
9. Якщо цілі не знайдені, система очікує або повертається до Drop залежно від стану.

Зупинка:

1. Натисніть **auto-stop** / **Auto operation stopped** у UI.
2. Переконайтесь, що робот у безпечній позі.

## 9. Моніторинг та відновлення

Під час роботи контролюйте:

1. Статуси в хедері (камера/робот/грипер).
2. Повідомлення про `Emergency stop`, `Connection Error`, `Camera stream offline`.
3. Стан програми: чи немає одночасно кількох активних операцій.

Типові дії відновлення:

1. **Камера недоступна**: перевірити USB, живлення, перезапустити стрім.
2. **Робот offline/error**: перевірити мережу, повторити тест з'єднання.
3. **Грипер недоступний**: перевірити IP Compute Box, живлення, `Test gripper`.
4. **Emergency stop**: зняти аварійний стан на контролері, повторно ініціалізувати робота в UI.

## 10. Процедура безпечної зупинки

1. Зупиніть активну програму (manual/auto).
2. Дочекайтесь завершення поточного руху або виконайте контрольовану паузу.
3. Переведіть робота у безпечну позу.
4. Вимкніть подачу команд із UI.
5. Закрийте застосунок.

Для Docker-сценарію:

```bash
docker compose down
```

## 11. Усунення несправностей

### 11.1 Немає детекцій

1. Перевірте, що модель завантажена.
2. Збільшіть освітлення та перевірте фокус.
3. Перегляньте `Confidence` та `IOU` пороги.

### 11.2 Помилки калібрування

1. Повторіть калібрування камери з більш стабільною дошкою.
2. Перевірте видимість маркерів ID 1/2.
3. Переконайтесь, що плита не зсунута після robot calibration.

### 11.3 Невірна точка pick/drop

1. Перевірте, чи актуальні `workspace_definition.npz` і `robot_calibration.json`.
2. Перевчіть Drop після змін у калібруванні.
3. Перевірте, чи використовується правильна система координат для поточного сценарію.

### 11.4 Нестабільний грипер

1. Перевірте мережу до Compute Box.
2. Перевірте параметри force/speed/target width.
3. Повторіть `Test gripper` у Setup.

## 12. Глосарій UI-термінів

| Термін в UI | Опис для оператора |
|---|---|
| **Calibration** | Вкладка налаштування камери, робочої зони і робота. |
| **Applications** | Робочі сценарії pick-and-place. |
| **Monitoring** | Стан системи, діагностика, телеметрія. |
| **Setup & Connections** | Підключення камери, робота, грипера і службові тести. |
| **Camera: live/off/error** | Поточний стан відеопотоку камери. |
| **Robot: idle/offline/error** | Поточний стан робота. |
| **Gripper: online/off/error** | Поточний стан грипера 2FG7. |
| **Begin calibrating robot** | Запуск покрокового калібрування робота по 3 точках. |
| **Detect plate markers** | Виявлення маркерів калібрувальної плити для трекінгу. |
| **Target class** | Клас об'єктів, які потрібно підбирати в Auto-режимі. |
| **Drop ignore radius (mm)** | Радіус навколо Drop-зони, де детекції ігноруються. |
| **Emergency stop** | Негайна аварійна зупинка руху. |
